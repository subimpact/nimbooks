# NimBooks demo video — phone recording script (2026-09-12)

Target: ~50 s, portrait, screen recording inside Nimiq Pay. No voiceover needed.
Upload as a YouTube Short ("NimBooks — the books for your Nimiq wallet" or similar), then send the link so submission.yaml + README can point at it.

## Prep (2 min)
- Nimiq Pay open & logged in. Open NimBooks once (warm), then close it before recording.
- Do Not Disturb / Focus ON — no notification banners.
- Brightness ~80%. Keep portrait throughout. Dark theme looks best (app default).
- Start screen recording: iPhone → Control Center ⏺ | Android → quick settings.

## The take (times approximate)
1. 0:00 — **Open.** Launch NimBooks from Nimiq Pay. Let it reconnect to the wallet; ride the flash of "Reconnecting…" to the dashboard.
2. 0:05 — **Overview.** Pause a beat, then scroll slowly: Total value → Balance details (available + staked) → Addresses → Analytics (7d/30d) → net-flow chart. Scroll slower than feels natural.
3. 0:13 — **History.** Tap History; scroll rows; tap one transaction → detail sheet → pause → close.
4. 0:21 — **Sign a receipt (money shot).** A received row with "Sign receipt" → tap → confirm in the wallet sheet → open Receipts → open the receipt → pause on the verified state.
5. 0:31 — **Request.** Request tab → amount (e.g. 5 NIM) + what for → Create request → pause on link/QR → Copy link.
6. 0:40 — **Export.** Export tab → statement export → share sheet slides up → pause → dismiss.
7. 0:47 — **Close.** Back to Overview. Optional flourish: leaf icon → stake panel for 2 s. Stop recording. (~50 s total)

## After
- Trim head/tail; keep under 60 s. Record 2-3 takes, pick the smoothest.
- Upload; send the link → yaml + README get updated in one commit, together with the fresh screenshots.
- If a scene plays up (e.g. no Sign receipt on a row), skip it — the rest carries.
- Privacy: real balance/history will be on camera — decide if that's fine for a public upload (otherwise sample-wallet scenes / rendered video).
